# Voter Registration Workflow Demo

Interactive academic demonstration of a proposed voter registration workflow.

## Open locally

Double-click `index.html`. Data is stored only in the current browser through localStorage.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html` (and optionally this README) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will show the public website address after deployment finishes.

## Scope

This is an academic demonstration, not an official COMELEC service. It uses fictional/sample information and does not complete voter registration, validate documents, collect biometrics, or make official decisions.
